小渡 · AI 热点公众号写作 Skill

给刚开始关注 AI 的读者，用「小渡」口吻写热点解读。流程绑死，不空话、不编事实。

查看 Skill / 打开仓库

一、帮谁

写给两类人：一是刚开始关注 AI、想搞懂「这件事到底意味着什么」的读者；二是要稳定产出 AI 热点公众号、又不想每次重新教 Agent 怎么写的人。装上这个 Skill，对 Agent 说「用小渡写某某热点」，就按固定流程出初稿。

二、四步怎么写

先写清：谁在读、真正问题、读后收获、核心判断、最强反方。写完必须等你确认，确认前不往下走。
列出 3–6 条主张。每条具体事实标来源：用户提供 / 已核实 / 小渡判断。材料不够就缩小范围或标「待核实」，不编。
约 1200–2500 字 Markdown。自称小渡，口头禅至少一次，结尾有短期/长期判断；禁「赋能」「闭环」这类空话；文末附「主张—来源」简表。
交稿前逐条过：人设、口头禅、收尾判断、无禁说、来源归属、任务书已确认、未编亲历、未绑 CLI/草稿箱/自动生图。

三、怎么装到 GitHub

仓库已开好。把目录拷进 Agent 能读到的 skills 路径即可： 
cp -R . ~/.agents/skills/ai-hotspot-wechat
或项目级： 
mkdir -p .agents/skills
cp -R . .agents/skills/ai-hotspot-wechat
核心文件是 SKILL.md。装好后说：「用小渡写一篇某某热点的公众号」。
